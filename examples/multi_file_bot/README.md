# Бот wgram из нескольких файлов

Структура: `main.py` запускает бота, `config.py` читает `.env`, модули в `handlers/` регистрируют команды и кнопки, `post.png` — фото для публикации.

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`, впишите токен и числовой ID канала.
3. Назначьте бота администратором канала с правом публикации.
4. Запустите из этой папки: `python main.py`.
5. Напишите боту `/post` в личном чате от имени администратора канала.

`.env` исключён из Git. Если меняете библиотеку в исходном репозитории, установите её из корня репозитория через `python -m pip install -e .`.

`post.png` можно заменить своим изображением с тем же именем. Для custom emoji в канале Telegram может требовать особые права бота; при отказе Telegram ошибка будет отправлена в личный чат.
